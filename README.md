# ssbuRecorder

スマブラの対戦結果を記録し、振り返るためのWebアプリ。

## 目的
自分の対戦結果を記録・分析する。
開発を通じて、要件定義・設計・実装・テスト・公開までを経験する。

## 想定する利用場面
- まずは自分1人で利用する。
- オンライン対戦やフレンドとの対戦後、1試合ごとに入力する。
- 初版はPCでの利用を中心とする。

## 初版の機能
- 対戦記録の登録・一覧表示・編集・削除
- 対戦数・総合勝率の表示
- 記録の保存

### 記録する情報
- 自分のキャラ：必須
- 相手のキャラ：必須
- 勝敗：必須
- 対戦日：当日を初期値として入力
- ステージ：任意
- 対戦メモ：任意

### 入力時の動作
- 1件の記録は1試合の結果とする。
- 勝敗を選んでから登録ボタンを押す。
- 登録後も、自分と相手のキャラの選択を残す。
- 登録後は勝敗を未選択に戻す。

## 初版の完成条件
公開したアプリで実際の対戦を10件登録し、以下を確認できること。
- アプリを閉じて開き直しても記録が残る。
- 対戦記録の一覧と正しい総合勝率を確認できる。
- 記録を編集・削除できる。
